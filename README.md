# SunSkySoft - GitHub Pages（アプリ配布サイト）

このリポジトリは、アプリ配布を目的としたシンプルな静的サイトの雛形です。

使い方:

- リポジトリをクローンして、ブラウザで `index.html` を開いて確認してください。
- バイナリ（リリース）を追加するには `assets/downloads/` にファイルを置いてください。
- ダウンロードページのチェックサムはリポジトリ内のファイルをもとに生成できます（例: `shasum -a 256 assets/downloads/*`）。

次のステップ:

- 必要なら GitHub Actions で自動デプロイ設定を追加します。
